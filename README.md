## Why This Kit Exists

Asking a language model to summarize raw public filings (procurement notices, municipal grants, regulatory dockets, or court registries) routinely fails in production for four mundane reasons:

1. **Clerical & structural registry traps:** Official forms contain trailing-zero typos (`540,000` entered instead of a `54,000` winning bid), multi-lot contract totals pasted repeatedly into every lot (`3 × 450k = 1.35M`), acronym collisions (`AI` = *Avian Influenza* in veterinary labs), and hallway renovations inheriting a technical department's name.
2. **Denominator confusion:** Mixing multi-year contract ceilings with annual cash outlays, conflating sole-source statutory awards (`bidCount: null`) with "missing data", or counting notice headlines instead of contracted money.
3. **Prose-to-dataset drift:** After cleaning an edge case in JSON, one chart caption, `<noscript>` block, translated page, or OpenGraph preview image silently retains yesterday's total.
4. **Dead-end static charts:** Newsrooms and social readers engage far more deeply when every claim links to a 1-click filtered view, an embeddable `?embed=1` widget, and direct primary-source filings.

`data-investigation-kit` turns the entire workflow—from raw-filing hygiene to interactive publication and multi-agent orchestration—into a **deterministic, zero-dependency harness**.

## Quick Start

Requires **Node.js 20+** (zero runtime npm dependencies).

```bash
# 1. Scaffold a new investigation workspace (dataset + spec + interactive explorer + OG card)
node ./bin/data-kit.mjs init ./my-investigation --title "Municipal Grid & Sensor Grants Audit"

# 2. Scan raw or cleaned records for 10x typos, multi-lot paste bugs, and entity drift
node ./bin/data-kit.mjs audit ./examples/civic-grants/data/raw-uncleaned-sample.json

# 3. Compute exact integer-cent KPIs, medians, category shares, and competition splits
node ./bin/data-kit.mjs kpis --spec ./my-investigation/investigation.spec.json

# 4. Regenerate the 1200x630 OpenGraph SVG social card from live KPIs
node ./bin/data-kit.mjs og --spec ./my-investigation/investigation.spec.json

# 5. Run the zero-drift verification gate across JSON, HTML, anchors, presets, and SEO tags
node ./bin/data-kit.mjs verify --spec ./my-investigation/investigation.spec.json
```

## CLI Reference (`data-kit`)

| Command | Purpose |
| :--- | :--- |
| `data-kit init <dir> [--title "..."]` | Scaffolds `investigation.spec.json`, starter `data/records.json`, zero-framework `site/` explorer (`?embed=1` ready), `assets/og-card.svg`, and `docs/`. |
| `data-kit audit <records.json> [--strict] [--json]` | Flags `TRAILING_ZERO_TYPO`, `MAGNITUDE_MISMATCH`, `MULTILOT_TOTAL_PASTED`, `ACRONYM_COLLISION`, `INCIDENTAL_PURCHASE_IN_CORE`, `AMBIGUOUS_NULL_BIDS`, and entity name drift. |
| `data-kit kpis [--spec <file>] [--format markdown\|json]` | Computes exact BigInt integer-cent sums, medians, notice-share vs. value-share tables, competitive vs. sole-source splits, dual date series (`publishedDate` vs. `eventDate`), and canonicalized repeat winners. |
| `data-kit verify [--spec <file>]` | Validates JSON schema, checks inline `[data-kpi="..."]` elements and `mustContainKpis` against live calculations, verifies `#anchors` and `data-preset` deep links, and checks SEO/OpenGraph/`hreflang` reciprocity. |
| `data-kit og [--spec <file>] [--out <path>]` | Renders a deterministic `1200×630` editorial SVG social preview card directly from computed KPIs. |
| `data-kit parallel-plan [--spec <file>] [--agents 4]` | Outputs conflict-free file-ownership partitions so multiple AI subagents can build ETL, frontend UX, prose, and verification gates in parallel without collisions. |

## Built-In Reader & Newsroom Mechanics

Every workspace generated by `data-kit init` ships with a dependency-free HTML/CSS/JS explorer designed for investigative editors and high-velocity social sharing:

- **Zero-Flash `?embed=1` Newsroom Mode:** Appending `?embed=1` hides article navigation and essay chrome before first paint, giving partner newsrooms a clean `<iframe>` database widget with source attribution.
- **1-Click Investigative Lenses:** Pre-configured filter pills (*All core*, *Single-bid awards*, *Sole-source*, *Pure scope*, *Incidental*) with live counts so readers surface key slices immediately.
- **1-Click `Copy quote + link` Citations:** Copies a factual, one-sentence summary of the active filter slice together with its exact URL query string (`?cat=software&single=1#explorer`).
- **Transparent Scope & Correction Layers:** Retains `incidental` facility records and `auditNote` explanations inside the public JSON file (excluded from core sums by default, inspectable via a single toggle).
- **Responsive & Print-Safe:** Tested layout rules from `360px` mobile cards up to `1440px` desktop grids, with `<noscript>` dataset fallbacks and `@media print` rules.

## Portable AI Agent Skills & Plugin Bundle

This repository doubles as a drop-in customization bundle for AI coding agents (**Claude Code**, **Google Antigravity**, **OpenAI Codex**, and **Cursor**):

```text
data-investigation-kit/
├── AGENTS.md                                      # Workspace epistemic & verification guardrails
├── plugin.json                                    # Plugin manifest (Antigravity / agent bundles)
├── rules/AGENTS.md                                # Always-on plugin rule sheet
└── skills/
    ├── registry-etl-and-hygiene/SKILL.md          # Safe pagination, ID joining & anomaly auditing
    ├── investigative-kpi-and-denominators/SKILL.md# Integer-cent KPIs & denominator framing
    ├── interactive-explorer-and-embed/SKILL.md    # Explorer UX, ?embed=1, lenses & SVG viewBoxes
    ├── editorial-verification-gate/SKILL.md       # Spec assertions, i18n parity & zero-drift gate
    └── parallel-investigation-orchestrator/SKILL.md# Multi-agent file partitioning & press kit prep
```

### Installing Skills into Your Agent Environment

- **Project-local (Claude Code / Codex / Antigravity / Cursor):**
  Copy `AGENTS.md` and `skills/` into `.agents/skills/` (or `.claude/skills/`) inside your investigation repository.
- **Global plugin install (Antigravity):**
  Clone this repository into `~/.gemini/config/plugins/data-investigation-kit` and restart the IDE to load all five skills and rules as a single toggleable unit.
